3. What is dependency injection ? What are the types of deendency injection ?
==> Dependency injection is machenism by which we can inject the dependent object into the target object.
    There are mainly 3 types of dependency injection .

    1. Field injection    - mechanism of injecting the dependent object into target object by using the target class field is called field injeciton. for this we use @Autowired
    2. Constructor injection  - mechanism of injecting the dependent object into target object by using the target class constructor is called constructor injeciton.
    3. Setter Injection  - mechanism of injecting the dependent object into target object by using the target class Setter method is called Setter injeciton.

    Special Case :
   
    4. Circular Injection - If A class is dependent on B class bean and B class bean is dependent on A class bean then it is called circular injection .
    5. Lookup Injection   - This usually occour in scopes . If two objects are connected and if the scope of 1st object is singleton & scope of 2nd object is prototype.

8. What is Autowiring in spring and what are the modes of autowiring ?
==> Auto wiring is the mechanism by which we can perform dependency-injection automatically. in this the container will identify which is dependent object and will inject that object
    to the target object.

	Modes of Autowiring are :
  	1. By Name        - Based on target bean variable name IOC will identify dependent bean and it will inject it.
			    Note : target bean variable name should match with bean id. If it will not match then IOC will not perform DI.

        2. By Type        - Based on the datatype of the variable it will perform the dependency injection .If the data-type is interface then if will check how may implementation
                            class it has. If it has 2 implementation class then IOC will get confuse which bean needs to injected. it will get ambiguity issue. to resole this issue
                            we will with 2 options :

			   1. autowire-candidate = false
                           2. primary = true


	Note : By-Name & By-Type will use setter injection.
 
        3. By Constructor - This is used to perform auto wiring by constructor.
        4. no (default)  - This indicates hey container please don't do autowiring I will do manual wiring

                      It will go to open state.
